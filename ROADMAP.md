# 🎯 Roadmap - Aligned Proposals

## ✅ MVP - Versão 1.0 (Completo)
- [x] Autenticação e gerenciamento de usuários
- [x] CRUD de clientes e orçamentos
- [x] Geração de PDF profissional
- [x] Envio gratuito via WhatsApp Web
- [x] Envio por email
- [x] Sistema de planos e assinatura
- [x] Integração Stripe (sandbox)
- [x] Dashboard com métricas
- [x] Interface responsiva com Tailwind

## 🚧 Próximas Funcionalidades (Versão 1.1)

### Alta Prioridade
- [ ] **CRUD de Produtos/Serviços**: Cadastrar produtos para usar nos orçamentos
- [ ] **Templates de Orçamento**: Salvar e reutilizar modelos prontos
- [ ] **Histórico de Versões**: Rastrear alterações em orçamentos
- [ ] **Notificações por Email**: Alertas de aprovação, rejeição
- [ ] **Multi-idioma**: Suporte a PT-BR e EN
- [ ] **Dark Mode**: Tema escuro no frontend

### Média Prioridade
- [ ] **Relatórios Avançados**: Gráficos, exportar Excel
- [ ] **Assinatura Digital**: Clientes assinarem orçamentos online
- [ ] **Comentários**: Sistema de comentários em orçamentos
- [ ] **Anexos**: Upload de arquivos nos orçamentos
- [ ] **Tags/Categorias**: Organizar orçamentos por categoria
- [ ] **Busca Avançada**: Filtros múltiplos e salvos

### Baixa Prioridade
- [ ] **API Pública**: Permitir integrações externas
- [ ] **Webhooks**: Notificar sistemas externos
- [ ] **App Mobile**: Versão React Native
- [ ] **Chat ao Vivo**: Suporte em tempo real
- [ ] **Marketplace de Templates**: Comprar/vender templates

- NPS > 50

- 10000 orçamentos/mês
- MRR: R$ 50.000
- Churn < 5%
